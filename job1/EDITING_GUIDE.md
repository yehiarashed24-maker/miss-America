# 📖 دليل تعديل وإدارة موقع مركز مصر أمريكا - محمد حمودة
# Egypt America Center - Website Editing & Management Guide

مرحباً بك! تم تصميم هذا الدليل لمساعدتك في تعديل وإدارة محتوى الموقع بسهولة وبشكل منظم.

---

## 📁 خريطة ملفات الموقع (Where things are located)

| الملف File | الوصف Description | ما يمكنك تعديله What to Edit |
| :--- | :--- | :--- |
| `assets/js/data.js` | **ملف البيانات الرئيسي** | بيانات الشركة، أرقام الهاتف، الوكالات، كتالوج المنتجات، ونصوص الترجمة. |
| `assets/i18n/ar.json` | **ملف الترجمة العربية** | نصوص الموقع باللغة العربية. |
| `assets/i18n/en.json` | **ملف الترجمة الإنجليزية** | نصوص الموقع باللغة الإنجليزية. |
| `assets/i18n/zh.json` | **ملف الترجمة الصينية** | نصوص الموقع باللغة الصينية. |
| `config.js` | **ملف الإعدادات وكلمات السر** | مفاتيح API، كلمة سر لوحة التحكم Admin، ومفتاح Web3Forms. |
| `index.html` | **هيكل الصفحة الرئيسي** | عناصر الصفحة الهيكلية وأقسام الموقع. |

## 🛠️ 1. كيفية تعديل معلومات الشركة وأرقام الاتصال
افتح الملف: `assets/js/data.js`
ستجد في بداية الملف كائن `company`:

```javascript
company: {
  name: "Egypt America Center - Mohammed Hammouda",
  nameAr: "مركز مصر أمريكا - محمد حمودة",
  headquarters: "مساكن الشناوي بجانب مسجد التوحيد عمارة ٢ مدخل أ ، المنصورة، مصر",
  hotline: "+20 10 01339300",
  whatsapp: "+20 10 01339300",
  email: "info@egypt-american.com"
}
```

## 🌐 2. كيفية تعديل أي نص أو عنوان في الموقع (العربية / English)
يمكنك تعديل أي نص في الموقع من خلال فتح ملفات الترجمة:
- **العربية:** `assets/i18n/ar.json` أو ملف `assets/js/data.js` تحت قسم `translations -> ar`
- **الإنجليزية:** `assets/i18n/en.json` أو ملف `assets/js/data.js` تحت قسم `translations -> en`

**مثال لتعديل وصف الهيرو (Hero Section):**
في `ar.json`:
```json
"hero": {
  "description": "للاستيراد والتصدير والوكالات التجارية - المورد الدولي والوكيل المعتمد لآلات التريكو الدائرية عالية السرعة..."
}
```

---

## 📦 3. كيفية إضافة منتج جديد إلى الكتالوج (Add New Product)

### الطريقة الأولى: من لوحة التحكم مباشرة 🚀 (الأسهل)
1. افتح الموقع واضغط على **لوحة التحكم** أو اذهب للرابط `#admin`.
2. ادخل كلمة السر (الافتراضية: `1990`).
3. اكمل الخطوة الثانية (2FA) بأي رقم مصرح.
4. املأ بيانات المنتج (الاسم بالعربي والإنجليزي والصيني، الصورة، الفئة، والوكالة) واضغط **حفظ ونشر المنتج فوراً**.

---

### الطريقة الثانية: من كود `assets/js/data.js`
افتح `assets/js/data.js` وابحث عن `products: [`، ثم أضف عنصراً جديداً مثل:

```javascript
{
  "id": "prod-custom-1",
  "name": "اسم المنتج بالإنجليزية",
  "category": "Machinery", // أو "Spare Parts"
  "brandId": "rel-tex", // كود الوكالة
  "brandName": "REL-TEX",
  "country": "Taiwan",
  "flag": "🇹🇼",
  "image": "assets/images/products/my_product.jpg",
  "shortDesc": "وصف قصير بالإنجليزية",
  "fullDesc": "وصف كامل بالإنجليزية",
  "translations": {
    "ar": {
      "name": "اسم المنتج بالعربي",
      "shortDesc": "وصف قصير بالعربي",
      "fullDesc": "وصف كامل بالعربي"
    }
  }
}
```

## 🏢 4. كيفية إضافة وكالة / شريك تجاري جديد (Add Brand Agency)
في `assets/js/data.js` تحت قسم `brands: [` أضف الكائن التالي:

```javascript
{
  id: "new-brand",
  name: "اسم الوكالة",
  subName: "تخصص الوكالة",
  country: "Germany",
  flag: "🇩🇪",
  badge: "Official Agency",
  logo: "assets/images/partners/logo.png",
  tagline: "شعار الوكالة",
  description: "وصف الوكالة"
}
```
